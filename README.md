Dự án: Website du lịch Hà Tĩnh-Server
=====================================

Giới thiệu dự án
----------------

Dự án nhằm mục đích giới thiệu du lịch,văn hóa,đặc sản hà tĩnh

Công nghệ
---------

**Back-end**

*   Nodejs
*   jwt
*   mongodb
*   Express
*   .....


**Front-end**

* Nextjs 15
* react-hook-form
* UI:Shadcn,tailwindcss
* ....

**Cơ sở dữ liệu**

  * Mongodb

**Test Api**

  * Postman

**Code Editor**

  * Vs code

**Deloy website**

  * Vps ubuntu 22.04
  * Ubuntu 22.04

Cách chạy dự án ở localhost
---------------------------

*   Clone dự án với git
*   Cấu hình file .env
*   Gõ npm i ==> npm run dev
